# 简历制作要点

用于简历改写、定向制作及完整求职资料维护。版式与交付选项按使用者的目标岗位和实际要求调整。只改一段文字时，直接交付该段，不自动扩建素材库或网页。

## 1. 先找事实，再做岗位表达

- 从最新素材和用户确认中提取五类信息：当时的问题、承担的任务、亲自作出的判断和动作、形成的产物及应用、结果的依据。缺少影响表述准确性的内容时问具体问题，继续完成不依赖答案的部分。
- 同一事实可按岗位调整重点、专业术语和叙述顺序，突出可迁移能力及持续投入的主线。避免把每段经历都硬改成同一种岗位经历。
- 适当包装包括提炼真实价值、补清动作逻辑、用准确专业词描述已有方法。不能把准备学习写成已经使用，把AI执行写成独立编码，把方案建议写成上线或增长成果。
- 区分本人工作、团队产出、项目总体规模、企业经营结果。用户口述的新事实优先于旧稿；其他AI生成的统计量和案例文字不是事实来源。

## 2. 每件事写成一条完整STAR

用小黑点开头，每条围绕一件事。基本结构为：

> • **具体工作模块：** 面对什么情况，为完成什么任务，我做了哪些关键动作，形成什么结果或应用。

- S是原来的情况或具体问题；T是要完成的任务；A是本人的关键行动；R是结果、交付、应用或已确认数据。背景和任务可以合并，四项应能从正文及紧邻的明确上下文中找到，不能只剩动作清单。
- 整体仍按项目背景、具体工作模块、产出应用组织，不机械打印S/T/A/R四个标签，不拆成四段凑字数。
- 判断取舍、协作、验证、商业价值和复盘可以穿插，但不能替代STAR。AI项目尤其写清用户任务、模型与规则分工、人工判断、实际检查和产出。
- 有数字时写清对象与口径，例如使用次数、使用人数、问卷套数、有效样本量。没有效果指标时，用已完成的原型、报告、规则、反馈修改或应用情况支撑结果，不强加提升百分比。
- 参与、协助、负责并非禁词，但后面必须接具体贡献；精通、熟练、掌握不单独充当技能证据。不得声称某个词一定导致ATS淘汰。

## 3. 对外文字积极、自然、准确

- 优先讲已完成什么、解决了哪部分问题、形成什么能力。删去无助于岗位判断的自我减分评价，例如尚未开展正式效果评估、整体目标尚未达成；需要说明阶段时直接写原型、方案、试用或已完成的功能范围。
- 内部核对备注不搬进简历。例如跨项目统计放在区域研究汇总项，写累计完成X份报告；团队数字写团队产出X，本人主笔Y。不要在某家公司下面堆跨项目数字，再补上述规模非该公司单项成果的尾注。
- 删除减分句后，仍检查上下文是否误导。不能因此暗示原型已投产、建议已产生公司业绩；必要边界用短而自然的主语和阶段词表达。
- 使用用户听得懂、面试时说得出的语言。少造词、少口号、少抽象名词叠加；一句话说清谁为解决什么做了什么。
- 内部素材库保留来源、分工、统计口径与待核实事项，供面试准备；被直接问到的事实如实回答。

## 4. 版式与时间层级

- 页数按信息量及投递要求确定，可制作一页精简版、两页定向版或更完整的通用版。页数服务内容，避免为填满而添加无关信息。
- 教育背景明显呈现学校、专业、学历、时间和代表荣誉。公司名称、职责或职位、日期加粗；主项目高于分项目，二者不能同一加粗等级。
- 同类经历按结束时间倒序，进行中的置前；公司下的项目保持归属，子项目也按时间倒序。未知时间不补造，只有年份时不擅自补月份。
- 一家公司保留一个经历块，出题工具、招聘工作台等用下一级模块展开，避免同一公司重复列项。
- 字体、同级字号、行距、缩进和日期格式保持一致。正文可从10—11pt尝试，按字体和实际渲染调整；优先精简重复文字、调整分页，避免逐页缩字挤满。
- 首页减少大块底部空白，兼顾自然段距与阅读密度，不靠过度拉大行距填满。标题与首条内容同页，跨页时保留足以识别项目的续接信息。
- 配色和照片沿用已确认版本；重点加粗动作、关键数据和产物，避免整段全粗。导出PDF保留可选择文本。

## 5. 素材库与可复制网页

- 完整资料维护采用两份基础Markdown：总库保留全部真实经历、过程、分工、数字口径及确认记录；分类库按岗位整理可调用模块，并以稳定经历ID关联总库，避免复制成多个冲突的事实源。
- 新补充先更新事实，再更新相关简历、网申文本和下载文件。只同步受影响的当前版本，历史稿保留归档；不把不同格式中的旧文当作新事实。
- 需要完整填写资料时，可准备本地可复制HTML，覆盖所有岗位的完整经历，不局限于最近一个投递方向。每项结构一致，可展开看全文、复制整段，也可复制最小单元。
- 最小单元包括公司或项目名称、职位、时间、项目背景、工作模块、产出应用；另设教育、荣誉、个人成就、自我描述和补充说明。技能及奖项无需强凑STAR。
- 自我描述按岗位提供版本；支持搜索或分类、显示字数、逐项复制。复制内容为纯文本，不夹带按钮、填写建议、内部备注或Markdown标记；实现复制失败时的选中文本备用方式。
- 完整版、简历精简版及字数受限版共享事实。按实际字段限制裁剪，不机械要求所有项目字数一样。个人联系信息和照片用于本地资料，公开网页另按授权选择。

## 6. 交付前快速检查

1. 逐条能找到S/T/A/R；动作属于本人，结果有依据，术语能结合经历解释。
2. 数字归属、日期、公司与职位一致；删去多余免责声明后没有留下误导。
3. 标题层级、字体字号、黑点缩进一致，教育明显，首页充实，没有孤立标题、溢出或文字截断。
4. 核对每页实际渲染及PDF文字；网页核对桌面、手机、展开、字数和复制功能。
5. 当前MD、HTML、PDF、复制库及下载包按本次范围同步，入口链接有效。交付当前入口，避免让用户在多个旧版本中猜选。
