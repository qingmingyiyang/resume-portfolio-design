# Resume Portfolio Design Skill

一个中文简历与求职资料技能：把真实经历写清楚，按岗位组织证据，统一简历、素材库和网申填写内容。

## 能做什么

- 用STAR检查情境、任务、行动与结果，保留自然表达。
- 提炼个人贡献、判断与取舍，积极表达已有成果，不编造数据。
- 整理总素材库及分类调用库，用稳定ID关联经历。
- 规范教育、公司、职位、日期与项目层级，检查时间倒序、字体和分页。
- 准备可展开、显示字数、复制最小单元的本地网申网页。
- 制作作品页面并检查移动端、打印和PDF文字完整性。

这是给AI助手使用的指令和参考文档，不是自动生成器，也不保证获得面试。实际输出取决于材料与所用工具。

## 使用

将本仓库目录保存为 `resume-portfolio-design`，放入所用助手支持的技能目录。在支持该技能格式的助手中调用：

```text
请使用 $resume-portfolio-design，按这个JD整理我的真实经历并优化简历。
保留STAR四要素，突出个人动作和结果，不补造数据。
```

也可以直接提供 `SKILL.md` 及相应参考文档作为任务指导。无需安装运行时依赖；生成或检查PDF、网页时由助手使用所在环境已有工具。

### 常用请求

- 检查每条经历是否包含背景、任务、行动与结果。
- 保留事实，改成适合用户研究或产品运营岗位的表达。
- 把素材整理成总库与分类库，并做可复制的网申网页。
- 调整两页简历的标题层级、字体和首页留白。

页数、颜色、照片与交付范围均以使用者要求为准。局部改写不会自动扩成全套资料工程。

## 文件结构

- `SKILL.md`：入口与规则优先级。
- `references/resume-playbook.md`：简历制作要点。
- `references/resume-methodology.md`：岗位匹配与经历分析。
- `references/online-form.md`：实际填表与离线填写稿。
- `references/html-portfolio-design.md`：网页与打印呈现。
- `agents/openai.yaml`：技能显示信息。

## 隐私与贡献

本仓库只包含通用方法，不包含个人简历、联系方式、项目数据或内部原始材料。使用时将私人素材保存在本地；提交Issue或PR前，请移除姓名、联系方式、客户资料和内部业务信息。示例应使用明确标注的虚构材料。

欢迎改进表达、可访问性和跨格式一致性。贡献时保持事实准确、范围清晰，不增加强制量化或虚构岗位经历的规则。
